# Diagnostic Report

## Overview

The Diagnostic Report converts a completed diagnostic attempt into a clear,
actionable summary of the user's current IELTS level. It is generated by the
Diagnostic Test Framework (`backend/app/services/diagnostic_service.py`) and
rendered on the frontend at `/diagnostic/result?attempt_id=<id>`.

The report is **deterministic (NO AI)**: every score, insight, and recommendation
is derived from the user's answers and stored attempt data via documented formulas.

The report displays **ten** sections, all in a beautiful, responsive UI:

| # | Section                  | Description                                          |
|---|--------------------------|------------------------------------------------------|
| 1 | Overall Estimated Band   | Mean of skill bands → IELTS band (0.5 steps) + CEFR  |
| 2 | Skill-wise Performance   | Band + accuracy bar per skill (all 6 domains)        |
| 3 | Accuracy                 | Per-skill accuracy % (objective sections only)       |
| 4 | Time Taken               | Total minutes spent on the diagnostic                |
| 5 | Strengths                | Skills/areas scoring above threshold                 |
| 6 | Weaknesses               | Skills/areas scoring below threshold                 |
| 7 | Recommended Focus Areas  | Ranked, actionable focus recommendations             |
| 8 | Suggested Weekly Hours   | Recommended weekly study time (5–20 hrs)             |
| 9 | Suggested Exam Timeline  | Estimated weeks until exam-ready                     |
| 10 | Roadmap Preview          | Personalized plan preview or CTA to generate one     |

## Report Computation

### Overall Estimated Band

Each of the six skill sections (`reading`, `listening`, `writing`, `speaking`,
`vocabulary`, `grammar`) receives a band score in 0.5 steps. The overall band is
the mean of all computed skill bands, rounded to the nearest 0.5.

```
overall_band = round( mean(skill_scores) / 0.5 ) * 0.5
```

### Skill-wise Performance & Accuracy

- **Objective** sections (reading, listening, vocabulary, grammar): graded
  right/wrong. Accuracy = `correct / answered * 100`. Band is mapped linearly
  from `BAND_FLOOR = 3.0` (0% accuracy) to `BAND_CEIL = 9.0` (100% accuracy),
  rounded to 0.5.
- **Subjective** sections (writing, speaking): either a rubric self-score
  (the client provides a 0–9 value) or a neutral default band (5.5). Their
  accuracy is reported as 0 (not accuracy-based).

### Strengths & Weaknesses

Derived deterministically from each skill's band/accuracy relative to the mean,
so the user always sees a balanced, honest breakdown.

### Recommended Focus Areas

The weakest skills (band < 6.5) are ranked by gap from a 7.0 reference band and
turned into actionable recommendations (e.g. "Master Reading fundamentals…"),
plus a technique recommendation per weak section. Maximum 5 items.

### Suggested Weekly Study Hours

```
base   = hour block by current band (5 / 8 / 10 / 12)
gap_hours = 2 × number of skills below 6.0
total  = clamp(base + gap_hours, 5, 20)
```

### Suggested Exam Timeline

```
base_weeks = weeks by current band (18 / 14 / 10 / 6)
adjustment = 2 × number of skills below 5.5
total      = max(4, base_weeks + adjustment)
```

### Roadmap Preview

If the user already has an active study plan, the preview shows its title, total
weeks, target band, and status. Otherwise it builds a lightweight preview with the
suggested target band (`overall_band + 1`, capped at 9.0), the weakest focus skills,
and the estimated preparation weeks — plus a CTA to generate a full plan.

## API Endpoints

- `POST /api/v1/diagnostic/attempts/{attempt_id}/complete` — finalize the attempt
  and compute/store the report.
- `GET /api/v1/diagnostic/attempts/{attempt_id}/report` — fetch the report.

### Report Response Shape

```json
{
  "attempt_id": "uuid",
  "user_id": "uuid",
  "overall_band": 6.5,
  "target_note": "Current estimated IELTS level based on your diagnostic.",
  "skill_scores": [
    { "section": "reading", "band": 7.0, "accuracy": 72.5 },
    { "section": "listening", "band": 6.5, "accuracy": 60.0 }

  }
}
```

## Frontend

The report is rendered at `frontend/src/app/diagnostic/result/page.tsx` inside a
responsive `DashboardLayout`. It includes:

- A header with the completion date, a **Regenerate** action, and a **Build My
  Study Plan** CTA.
- A hero **Overall Band** card (band + CEFR + time taken + avg accuracy).
- **Skill-wise Performance** bars with per-skill accuracy and band.
- Right-column cards for **Strengths**, **Weaknesses**, and **Recommended Focus**.
- Bottom cards for **Suggested Weekly Study Hours** and **Suggested Exam Timeline**
  (with start/target dates).
- A **Roadmap Preview** card (renders the plan, or the CTA to generate one).
- Loading, error, and empty states.
